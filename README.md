# WebTech Project: Bank of India Clone and Calculator

This repository contains two main components:  
1. **Bank of India Clone** - A static clone of the Bank of India website.
2. **Calculator** - A simple web-based calculator.

## Project Structure

The project has the following folder and file structure:

```
├── Bank of India Clone
│   ├── font-awesome-4.7.0/
│   ├── images/
│   ├── index.html
│   ├── script.js
│   └── styles.css
├── Calculator
│   ├── calculator.html
│   ├── script.js
│   └── styles.css
```

### 1. **Bank of India Clone**
This part of the project is a static HTML-based clone of the **Bank of India** website. It demonstrates a simple layout of a banking website with basic navigation and content structure.

- **index.html**: The main HTML file containing the structure of the webpage.
- **script.js**: JavaScript file for handling any interactive features or behaviors on the page.
- **styles.css**: CSS file for styling the webpage.
- **font-awesome-4.7.0/**: Folder containing Font Awesome icons used throughout the site.
- **images/**: Folder containing images used in the clone.

### 2. **Calculator**
A simple calculator built using HTML, CSS, and JavaScript. This component allows users to perform basic arithmetic operations.

- **calculator.html**: The main HTML file for the calculator.
- **script.js**: JavaScript file that contains the logic for performing calculations.
- **styles.css**: CSS file for styling the calculator interface.

## Features
- **Bank of India Clone**:
  - Static website layout with images, icons, and links mimicking the Bank of India website.
  - Font Awesome icons for design enhancement.
  
- **Calculator**:
  - Basic calculator functionality (addition, subtraction, multiplication, division).
  - User-friendly design with simple input and output fields.

## Setup and Usage

To run this project locally:

1. Clone the repository to your local machine:
   ```bash
   git clone <repository-url>
   ```

2. Open the `index.html` file in a browser to view the **Bank of India Clone**.

3. Open the `calculator.html` file in a browser to use the **Calculator**.

No additional setup or server-side configuration is required, as both components are static web pages.
